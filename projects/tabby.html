Tabby — Tab Manager & Memory Saver

Close duplicate tabs, search across every window, and auto-suspend idle tabs to save memory.

Get on Chrome Web Store

Overview

Tabby is a fast, private tab manager and memory saver — built to replace the heavy, over-permissioned suspenders of the past.

Too many tabs slowing your browser to a crawl? Tabby frees memory using Chrome's built-in tab-discard engine, so inactive tabs stop hogging RAM but stay right where you left them. Click one and it reloads instantly.

Only three permissions are required: tabs, storage, and alarms — no content scripts, no access to page content or browsing data.

Features

  • ✓Close duplicate tabs in one click, or automatically as they open
  • ✓Search every open tab by title or URL across all windows
  • ✓Auto-suspend idle tabs with a configurable threshold (default 30 minutes)
  • ✓Smart exceptions for the active tab, pinned tabs, and tabs playing audio
  • ✓Personal allowlist for sites that should never be suspended
  • ✓Optional tab-count badge
  • ✓Settings sync across your own Chrome profiles
